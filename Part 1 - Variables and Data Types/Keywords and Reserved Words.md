# Keywords and Reserved Words
These are just a few examples of reserved words we will be using in this project. For an extensive list, check [this source](https://learn.perl.org/docs/keywords.html).

| Type                          |  Terms                                                                                     |
|-------------------------------|--------------------------------------------------------------------------------------------|
| Control structure             | if, else, elsif, while, for, foreach, until, unless, goto, last, next, and                 |
| Functions                     | print, chomp, chop, push, pop, keys, values, open, close, sub, return, and undef |
